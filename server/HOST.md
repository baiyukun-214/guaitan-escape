# 《夜班来电》主持人底稿（含完整剧透）

仅供后端/创作使用，不可放入public、前端bundle、游戏未结算公共状态。本作原创；创作依据只有用户描述的玩法，未读取《恶魔法典》视频或照搬其剧情。

## 核心命题

恐怖来自被掩盖的求助，而不是不守神秘禁令就凭空死亡。看似“对已停用热线打来的电话”，最终是同一场事故的本地检修回放。桌面“血量”代表精神负荷/有限行动力；搜证错误对应电气风险、操作超时及压力，不描绘血腥伤口。

## 真相时间线

- 11月6日，陈原主管把槐桥地下通道违规作为临时避雨点，未检查自动闸门断电锁闭问题。
- 23:17，洪水涌入，女孩小禾打热线求援。前班接线员林遥接听并做双路录音。
- 23:18，陈原在人员仍未撤离时切断主继电器，想把求助中断解释为设备问题。门禁记录保留了刷卡。
- 23:19，陈原签“人员已清空”，但撤离签收栏空白，自动闸门仍关闭。纸背压痕“停电后再报”与记录共同指出有意伪报。
- 23:21，林遥用蓝色备用电池接通应急线路，继续教小禾带大家上干燥的上层检修梯。
- 23:26，小禾转动手动绞盘开闸，众人撤离。最后半句不是临终遗言，是成功撤离的报告。
- 游戏当晚23:40，热线临拆机检修自动播放11月6日封存录音；三声短鸣是同步标记，墙钟因停电停在23:17。电脑无新呼入是实线索。

陈原的违规开放与具体动机只作人物背景，基础线索不能证明其精确心理，因此不列必答要点。没有任何需要凭空引入的鬼怪或时间循环设定。题外推测无需AI肯定；关键六事实说清即可。

## 规则为何存在

1. 回放键/时间戳：拆解时间混淆。
2. 三声短鸣：拆解“来电者回应”。
3. 红色主电源/蓝色备用电池：搜证安全谜题，也解释主线救援可行性。
4. 口头清空需书面与设备交叉核对：引导证据思维，不直接判主管清白。
5. 双路音轨校验：让两人任务成为拆出完整录音的劳动，不是故事外猜数题。
6. 蓝纸夹层：明确提示隐藏补给，不靠主持人临时赏赐。
7. 上层检修梯和手动绞盘：提前埋下可行逃生路线，避免终盘凭空开一扇门。

## 主持执行流程

1. 三人选装备，初始5血，房主指定一人查档。
2. 阅读导语、7规则。团队对5个公开方向各给一句猜想；分别检查F1到F5对应轴。仅报总数，>=3无损，否则待本人确认团队1血。
3. 单人安全操作：断开红色电源；交叉核对纸质签名和闸机日志；到上层检修梯用绞盘。每次成功按S1/S2/S3顺序取卡。失败扣自己1血。
4. 双人校验：发出1—15秒测试信号，另一个猜秒数，给末位提示。正确顺次得D1/D2/D3，错3次扣报时员1血。3张各能在其对应的角色视角中看到。
5. 每条任务实扣3血后发全部基础卡。零血应急策略见README，无后台任意加血/改规则接口。
6. 收齐任务卡进入讨论；私密卡需持有人主动公开。零血仍可公开、组合。
7. 自由文本还原，按F1—F6评分，不要求原句，不要求背景动机。答错产生待协商损伤，确认后才扣血，再答；全员零血或全覆盖后结算。

## 六个必答事实（不是六个关键词）

- **F1 事故**：槐桥地下通道洪水，被困求助。日期时间是证据，不作为严格背诵项。
- **F2 声音来源**：今晚是旧录音的本地检修回放，不是亡者或新外线。
- **F3 中断**：主管陈原切断主继电器/主电源。
- **F4 掩盖**：陈原在人未撤完时伪报清空。
- **F5 援助**：林遥接备用线继续指导。
- **F6 结果**：上干燥的上层检修梯，用手动绞盘开闸，众人撤离。

离线练习模式只近似匹配这些事实，必须在界面明确写“非AI”。真正AI只做结构化语义标注，程序决定覆盖数和扣血；服务故障不能自动判玩家错误。

## 结局

- **一语中的 / 信号留存**：F1—F6全覆盖。AI不得追加未铺垫反转；展示完整真相与本局证词。
- **全员零血 / 信号熄灭**：失败但解封底稿，方便复盘；不永久惩罚玩家。
- **中间反馈**：毫无头绪0—1、初见端倪2—3、接近真相4—5。只报等级和覆盖总数，不逐个指认缺失事实，保留推理空间。
